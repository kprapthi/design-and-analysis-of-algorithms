# Package Loading Optimizer

## Short description
A small desktop application that uses the First Fit, First Fit Decreasing, and Best Fit Decreasing approximation algorithms to create efficient loading plans for packages placed into fixed-capacity containers.

## Main features
- Editable package sizes and container capacity
- Comparison of FF, FFD, and BFD
- Best result and lower-bound calculation
- Container utilization and unused-space analysis
- Detailed loading plan for each method
- Resizable and maximizable GUI
- Input validation and clear error messages

## Technologies used
- Python 3
- Tkinter / ttk
- Python standard library only

## How to run
```bash
python main.py
```
