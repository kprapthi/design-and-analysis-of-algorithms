# Implementation and Performance Analysis of Interpolation Search

A GUI-based mini-project implementing Interpolation Search and comparing it with Binary Search.

## Features
- Search an element in a sorted array.
- Display the index and number of comparisons.
- Compare execution time for different input sizes.
- Compare Interpolation Search and Binary Search.
- Simple Python Tkinter GUI.

## How to Run

```bash
python main.py
```

A separate GUI window will open.

## Files
- `main.py` - Main application.
- `README.md` - Project description.
