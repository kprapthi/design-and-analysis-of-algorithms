# RouteWise – Delivery Route Optimizer

## Project title
RouteWise – Delivery Route Optimizer using TSP Branch and Bound

## Short description
A professional desktop mini-project for finding a minimum-cost delivery round trip through multiple locations. The supplied Travelling Salesman Problem Branch and Bound implementation remains the core algorithm, with the supplied brute-force routine used to verify the optimal result.

## Main features
- Professional academic-style desktop interface
- Editable delivery locations and route-cost matrix
- Branch and Bound with matrix reduction
- Optimal delivery tour and minimum cost
- Nodes expanded and execution-time analysis
- Brute-force optimality verification
- Route-by-route verification table
- Input validation and clear error messages
- Resizable and maximizable interface
- Example data for immediate demonstration

## Technologies used
- Python 3
- Tkinter / ttk
- Python standard library

## How to run
Open a terminal in the project folder and run:

```text
python main.py
```

No external packages, database, internet connection, or web server are required.
