# N-Queens Placement Optimizer

## Short description
A small desktop placement-planning application that uses the N-Queens backtracking algorithm to generate and inspect conflict-free queen arrangements for a configurable board size.

## Main features
- Editable board size from 4 to 12
- Backtracking-based N-Queens solver
- Visual chessboard solution preview
- Browse all generated solutions
- Solution details table
- Backtrack count and execution-time analysis
- Resizable and maximizable GUI
- Input validation and clear error messages

## Technologies used
- Python 3
- Tkinter / ttk
- Python standard library only

## How to run
```bash
python main.py
```
