# QuickSort Studio – Inventory Price Sorter

## Project title
QuickSort Studio – Inventory Price Sorter using Randomized Quick Sort

## Short description
A small desktop-style application for sorting product prices efficiently. It uses the supplied deterministic Quick Sort and Randomized Quick Sort implementations, then compares their comparisons and execution time across different input patterns.

## Main features
- Editable product-price input
- Deterministic and Randomized Quick Sort
- Direct price-sorting result
- Benchmark comparison for random, sorted, reverse, and nearly sorted data
- Comparisons and execution-time analysis
- Changeable visual themes
- Responsive interface with maximize/fullscreen support
- Clear validation and status messages
- No server, database, API, or internet connection required

## Technologies used
- Python 3
- HTML5, CSS3 and JavaScript
- Python standard library for the desktop launcher

## How to run
Make sure Google Chrome, Microsoft Edge, Chromium, or Firefox is installed.

From the project folder run:

python main.py

No pip installation is required.

## Files included
- main.py – local desktop-style launcher
- index.html – complete interface and Quick Sort implementation
- README.md – project information and run instructions
